# zesty-ladder-kit

Full-stack developer · Elixir and LiveView

给自己省点事的小工具

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/zesty-ladder-kit.git
cd zesty-ladder-kit
npm install
```
